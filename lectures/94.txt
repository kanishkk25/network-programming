point yeh hain ki connection establish ho gaya, hum jab fetch karenge toh ek naya socket banega, ab woh fetch karate samay bane ya pehle bane we don't care, humko toh woh tab milega jab hum fetch karenge, jab accept karenge connection request 

toh ek naya socket banega, socket usi port number se bind hoga jis port se woh listening socket bound tha, par usko associated kiya jaayega jis client se connection ki request aayi hain uske port se + uske IP se + protocol

ab jab data aayega toh barabar uss socket se related queue mein pahuch jaayega, matalab jab humko data receive karana hoga tab bhi socket descriptor batana padega, jab hume kuch send karana hain tab bhi hum socket descriptor banayenge - socket descriptor ke bharose eidhar kuch send ki queue hogi usme daal diya jaayega, eidhar send ki queue ki wajah se woh appropriet program tak pahucha jaayega, kyuki jab pahuchega toh IP aur port number hoga

toh agar Program A ko bhejana chahte hain toh isse related socket descriptor hoga hamare paas, toh uss socket descriptor ke bharose hum likhenge toh Accepted connection mein kahi toh bhi uss socket descriptor ke against send queue hogi usme likha jaayega aur uski wajah se woh barabar program A tak pahuch jaayega kyuki eidhar sab program ka IP/port wagera sab hain
