C Programming Language - Explicitly set port on client side

previous session humne client ka ip and port determine karane ka code likha tha

ab client side par woh socket jis port ke saath bind kiya jaata hain woh port number dynamic rehta hain, ab hum chahate hain ki hum specify kare, that should not be done ideally par kar sakate hain 

toh dekhate hain kaise kiya jaaye -

struct sockaddr_in se ek structure banayenge 
hum specify karenga sin_family - AF_INET

then hum chahenge jo sin_addr structure hain phir uss sin_addr mein jo s_addr hain usko underlying hardrware pe jitane bhi IP available hain usme se kisi ke saath bhi associate kardo toh INADDR_ANY

aur hum sin_port ko host to network karke assign karenge (32333)	

phir bind ko call karenge - 

1st argument - client socket descriptor
2nd argument - address of that structre
3rd argument - size of structure

let's do it ->

this is how we can bind the client to a specific port, should not be done ideally

basically jab ek socket bind hota hain kisi port ke saath, toh aap usko jab close karate ho toh close function turant return karwa deta hain par thhoda sa time lagata hain resources release karane ke liye jo bhi hain

pehle dynamic port tha toh jo port available hain woh le liya jaata tha 

par abhi specific port kar diya (32333) aur application chal ke khatam ho gayi par jab next time chalayenge toh ho sakata hain woh release na ho tab tak toh isliye woh use mein nahi aa paayega, matalab socket se woh port (32333) bind nahi kar paaya kyuki woh port free nahi tha
