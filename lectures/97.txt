toh hona chahiye ki machine A pe jo bhi hain woh convert karo Network Byte Order mein - phir machine B par jaayega toh phir waha jo bhi hain usme convert karo


toh host to Network Byte Order, ke liye function hain - htons

network to host byte order ke liye function hain - ntohs
(yaha host machine B)

toh ek unsgined short type ka data convert karane ke liye hain aur ek long type ka data

ipv4_address bana struct sockaddr_in se sume sin_addr field hain uske against yeh "192.168.1.55" IP set karana hain, toh uske liye

inet_aton function hain
alpha neumeric to network 

1st argument IP dena hain jo set karana hain (char * - base address of char array)
2nd argument woh structure ka address jiske sin_addr ke against yeh IP set karana hain
(inet_aton agar fail ho gaya toh 0 return karega)

result=inet_aton(ip,&ipv4_address.sin_addr);

ab uss ipv4_address (struc sockaddr_in se bana structure) mein ek field hain sin_port iske against port number 37987 set karana hain toh -

htons (host to network short) ek function hain, usko woh port number jo set karnana hain woh dena hain, phir htons function jo return karega usko

ipv4_address (type - struct sockaddr_in) ke sin_port ko assign karana hain -

ipv4_address.sin_port=htons(port);



ipv4_address (struct sockaddr_in) mein jo IP hain hume woh dekhana hain toh -

ptr=inet_ntoa(ipv4_address.sin_addr);  // return type is char *

inet_ntoa (network to alphanumeri) function ko woh IP dena hain jo ipv4_address (struct sockaddr_in) ke sin_addr mein hain, inet_ntoa uss IP ko as a string (char array) kahi rakhega aur uska address dega,

inet_ntoa jis string ka base address de raha hain woh ek static buffer hain, toh woh next call par overwrite ho jaayega, toh apani responsibility hain turant usko kahi copy karle toh -

strcpy(decoded_ip,ptr);


ipv4_address (struct sockaddr_in) mein jo port number hain hume woh dekhana hain toh -

ntohs (network to host short) function hain usko ipv4_address (struct sockaddr_in) mein jo sin.port hain woh dena hain, yeh ntohs function woh port number return kar dega (uint16_t return type hain function ka which is basically unsigned 16 bit int)

printf("Port is %u\n",ntohs(ipv4_address.sin_port));

{
struct addrinfo hints;
int result;
struct addrinfo *ptr2top_node,*t;
int server_socket_descriptor;
struct sockaddr_storage client_socket_storage;
socklen_t client_sockaddr_size;
struct sockaddr_in *client_sockaddr_in;
int client_socket_descriptor;

unsigned short int client_port;

// setup hints structures
memset(&hints,0,sizeof(hints));
hints.ai_family=AF_INET;
hints.ai_socktype=SOCK_STREAM;
hints.ai_flags=AI_PASSIVE;

// call to getaddrinfo
result=getaddrinfo(NULL,"9696",&hints,&ptr2top_node);
if(result==-1)
{
printf("Error : %s\n",gai_strerror(errno));
return 0;
}

for(t=ptr2top_node;t!=NULL;t=t->ai_next)
{
server_socket_descriptor=socket(t->ai_family,t->ai_socktype,t->ai_protocol);
if(server_socket_descriptor==-1) continue;

result=bind(server_socket_descriptor,t->ai_addr,t->addrlen);
if(result==-1)
{
close(server_socket_descriptor);
continue;
}
break; 	// socket creation and bind call done with no errors
}

// release linked list
freeaddrinfo(ptr2top_node);

if(t==NULL)
{
printf("Unable to create socket\n");
return 0;
}

result=listen(server_socket_descriptor,100);
if(result==-1)
{
printf("Unable to listen for connections\n");
printf("Error : %s\n",strerror(errno));
close(server_socket_descriptor);
return 0;
}

while(1)
{
printf("Server is ready to accept connection on port 9696\n");

client_sockaddr_size=sizeof(struct sockaddr_storage);

// accepting connection from backlog queue, if backlog queue is empty wait for connection

client_socket_descriptor=accept(server_socket_descriptor,(struct sockaddr *)&client_socket_storage,&client_sockaddr_size);

if(client_socket_descriptor==-1)
{
printf("Unable to accept connection request\n");
printf("Error : %s\n",strerror(errno));
continue;
}

printf("Connection request arrived and accepted\n");

if(client_sockaddr_size<=sizeof(struct sockaddr_storage))
{
if(client_sockaddr_storage.ss_family==AF_INET)
{
client_sockaddr_in=(struct sockaddr_in *)&client_sockaddr_storage;

strcpy(client_ip,inet_ntoa(client_sockaddr_in->sin_addr));
client_port=ntohs(client_sockaddr_in->sin_port);

printf("Client IP/Port is %s (%u)\n",client_ip,client_port);
}
}
else
{
printf("Unable to determine client IP/port\n");
}

// some code to send response

// close client connection
close(client_socket_descriptor);
}

close(server_socket_descriptor);
return 0;
}

getsockname() function ko arguments dena accept() function jaisa hi hain

accept() → Accepts a new incoming client connection on a listening socket and gives you a new socket to communicate with that client. Used to accept a new incoming client connection on a listening socket. It creates/returns a new socket for that client.

int accept(
    int sockfd,
    struct sockaddr *addr,
    socklen_t *addrlen
);

sockfd → listening socket
addr → output: gets the address of the client that connected
addrlen → input/output: size of addr / actual size written


getsockname() → Tells you the local address (IP + port) of an existing socket. Used to find the local address (IP + port) of an existing socket.

int getsockname(
    int sockfd,
    struct sockaddr *addr,
    socklen_t *addrlen
);
sockfd → socket whose own local address you want
addr → output: gets that socket's local address
addrlen → input/output size



struct sockaddr is a generic structure used to represent a socket address.

A socket address contains information such as:
Address family → IPv4, IPv6, etc.
IP address
Port number

struct sockaddr is generic, so it is not specifically designed for IPv4 or IPv6.

There are specific structures for different address types:

struct sockaddr_in → IPv4
struct sockaddr_in6 → IPv6
Other address families can have their own structures.

Socket functions commonly use struct sockaddr * so that the same function can work with different address types.

For example, accept() and getsockname() use struct sockaddr * because they should be able to work with IPv4, IPv6, etc.

struct sockaddr_storage is also a generic socket-address structure, but it is designed to be large and properly aligned enough to store different types of socket addresses, including IPv4 and IPv6.
